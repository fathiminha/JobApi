# Job API

A simple ASP.NET Core Web API project developed for learning and practicing .NET development.

## Technologies Used
- C#
- ASP.NET Core Web API
- Visual Studio / Visual Studio Code

## Features
- Create a new job
- Retrieve all jobs
- Retrieve a job by ID
- Update job details
- Delete a job

## Purpose
This project was created for learning purposes to understand the fundamentals of ASP.NET Core Web API, controllers, models, HTTP methods, and RESTful API development.

## Getting Started

1. Clone the repository.
2. Open the project in Visual Studio or VS Code.
3. Run the application using:

```bash
dotnet run
```

4. Test the API endpoints using Swagger or Postman.
